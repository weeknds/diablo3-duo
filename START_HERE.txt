Diablo III Duo — experimental live preview

The native 0.2.0-dev package provides Character, Equipment, Skills and Map
views on the Thor's lower screen, with no character imagery. It reads one
exact game build; it never writes game memory or equips items.

Start with README.md, docs/installation.md and docs/compatibility.md.
Current device observations and limits are in docs/validation.md and
unfinished work is in docs/next-step.md. Reader internals are in docs/reader.md.

Native package:
  python3 native/test.py
  python3 native/build.py --ndk /path/to/android-ndk-r28c --output dist/native-0.2.0

The native build needs an explicit macOS NDK r28c. Tests need Clang; Python
3.10+ is required. No game files are needed for public builds or tests.

Older static 0.1.1-dev package, with no live reader:
  python3 tools/build.py --check
  python3 tools/build.py

Both outputs have the same .dsmod.zip filename in different directories.
Choose the native release for live features. Use a separate test profile
and preserve saves. Never publish game archives, keys, firmware, saves,
extracted art, raw diagnostic logs or private device captures.
